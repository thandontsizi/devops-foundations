# Cloud and Automation Learning Repository:
## Overview:
This repository documents my hands on learning across Linux, Git, Networking, Docker, and Cloud fundamentals.

It contains structured practice, commands, small system-level exercises, and experimental projects. The goal is to build strong foundations through repetition and real command-line work. 
This is a learning repository. It is not intended to be a polished portfolio.

For recruiter-facing production-style projects, see this repository: "https://github.com/thandontsizi/cloud-and-automation-portfolio.git"


## How to Use This Repository:
If you are reviewing this repository:
- This repo demonstrates how I build technical foundations from the ground up.
- It includes command references, structured exercises, and practical system tasks.
- Projects here are learning focused and may not be production-polished.

If you are learning alongside it:
- Follow the folders in numerical order.
- Run the commands yourself and repeat the exercices.
- Break things. Fix them. Repeat.
- Treat this as structured practice and not a final guide.

## Repository Structure:
### 01-Linux-Basics:
Core Linux system administration fundamentals:
- File system navigation.
- Users and permissions,
- Processes and services.
- System inspection and auditing: Includes small system-level projects to apply concepts.

### 02-Git-Basics:
Version control fundamentals:
- Git configuration.
- Branching and merging.
- Staging and commits.
- Working with remote repositories: Exercises focus on workflow discipline and repository hygiene.

### 03-Networking-Fundamentals:
Foundational networking concepts and Linux networking tools:
- IP addressing basics.
- Network inspection commands.
- Service connectivity testing: Hands-on exercises reinforce command-line understanding.

### 04-Docker-Basics:
Container fundamentals:
- Installing and managing Docker.
- Working with images and containers.
- Writing basic Dockerfiles.
- Container lifecycle management: Includes practical container experiments and simple projects.

### 05-Cloud-Core-Focus:
Cloud fundamentals (AWS focus):
- Core service concepts.
- CLI usage.
- Infrastructure understanding: This section will evolve into structured cloud exercises and deployment experiments.

## Learning Philosophy:
This repository follows a fundamentals-first approach:
1. Understand the system.
2. Use CLI directly.
3. Repeat until concepts are second nature,
4. Then build projects.

Commands, tests, and repetition are intentional. Depth comes before abstraction.

Each folder represents a learning block with:
- README.md -> Concepts and explanations.
- commands.md -> Commands to practice.
- tests.md -> Questions to test understanding.
