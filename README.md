# Infrastructure Learning Repository:
## Overview:
This repository documents my hands on learning across Bash, Linux, Git, Networking, Docker, and Cloud fundamentals.

It contains structured practice, command references, and self-tests. 
The goal is to build strong foundations through repetition and real command-line work. 

This is a learning repository. It is not intended to be a polished portfolio.

For recruiter-facing production-style projects, see this repository: "https://github.com/thandontsizi/infrastructure-engineering-projects.git"


## How to Use This Repository:
### If you are reviewing this repository:
- This repo shows how I build infrustructure fundamentals from the ground up.
- It includes command references, structured exercises, and applied practise.
- Projects here are learning-focused and may not be production-polished.

If you are learning alongside it:
- Follow the folders in numerical order.
- Run the commands yourself and repeat the exercices.
- Break things. Fix them. Repeat.
- Treat this as structured practice and not a final guide.

## Repository Structure:
### 00-Bash-Basics:
Bash scripting necessities:
- Shell navigation and command execution.
- Variables and environment variables.
- Redirection and pipelines.
- Basic scripting (conditionals, loops, functions).

### 01-Linux-Basics:
Core Linux system administration fundamentals:
- File system navigation.
- Users and permissions,
- Processes and services.
- Logs and basic troubleshooting.

### 02-Git-Basics:
Version control fundamentals:
- Git configuration and repo setup.
- Branching and merging.
- Staging and commits.
- Working with remote repositories (push/pull).

### 03-Networking-Fundamentals:
Foundational networking concepts and Linux networking tools:
- IP addressing and routing basics.
- Connectivity testing.
- Port inspection.
- Basic troubleshooting workflows.

### 04-Docker-Basics:
Container fundamentals:
- Installing and managing Docker.
- Working with images and containers.
- Writing basic Dockerfiles.
- Container lifecycle management.

### 05-Cloud-Core-Focus:
Cloud fundamentals (AWS focus):
- Core AWS concepts.
- CLI basics.
- Foundational cloud infrastructure understanding.

## Learning Philosophy:
This repository follows a fundamentals-first approach:
1. Understand the system.
2. Use CLI directly.
3. Repeat until concepts are second nature.
4. Then build projects.

Each folder represents a learning block with:
- README.md -> Overview and objectives.
- commands.md -> Commands to practice.
- tests.md -> Questions to test understanding.
