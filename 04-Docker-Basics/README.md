# Docker Basics:
## Purpose:
This folder documents my learning of Docker fundamentals, including containerization concepts, core Docker commands, and container lifecycle management.

## Key Concepts:
- Docker Images: Read-only templates used to create containers.
- Docker Containers: Running instances of images.
- Dockerfile: A text file that details or defines how an image is built.
- Docker Engine: The service responsible for running containers.

## What I Learned:
- How Docker differs from virtual machines.
- How images and containers relate to each other.
- Basic container lifecycle commands.
- How Dockerfiles are used to build images.

## Tools Used:
- Docker.
- Linux (Ubuntu).
