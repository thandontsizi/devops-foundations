# JSON Fundamentals:

## Objective:
This section focuses on learning JSON as a structured data representation and interchange format.

The goal is to become comfortable reading, understanding, creating, and reasoning about JSON data and its structure.

---

## Focus:
- Understanding JSON and why it is used.
- Working with JSON objects and key/value pairs.
- Working with JSON arrays.
- Understanding JSON value types.
- Understanding nested JSON structures.
- Distinguishing JSON from prom programming language data structures.
- Identifying valid and invalid JSON.
- Understanding how JSON structure represents relationships between data.

---

## Folder Structure:
- **README.md:** Overview of the JSON Fundamentals learning block.
- **commands.md:** JSON syntax, structures, examples, and useful operations for working with JSON.
- **tests.md:** Concept checks, reasoning questions, practical scenarios, and troubleshooting exercises.

---

## Approach:
Learning is reinforced through:
- Understanding the purpose and structure of JSON before learning syntax.
- Relating JSON structures to familiar concepts such as entities, attributes, and relationships.
- Reading and analysing JSON examples.
- Writing JSON by hand.
- Identifying valid and invalid JSON.
- Reasoning about how nested data is represented.

---

## Outcome:
By the end of this section I should be able to:
- Explain what JSON is and why it is used.
- Identify JSON objects, keys, arrays, keys, and values.
- Recognise the different JSON value types.
- Understand and construct nested JSON structures.
- Distinguish between JSON data and programming language data structures.
- Identify common JSON syntax errors.
- Read and reason about structured JSON data.
