# Bash Basics:
## Overview:
This section or folder builds strong Bash fundamentalsfor infrastructure engineering.

Bash is the tool that ties together everything in this learning path:
- Linux system administration.
- Automation and scripts.
- Docker and cloud CLIs.
- Troubleshooting workflows.

The end goal of this section is to confidently write practical scripts, not just run commands.

----------------------------------------------------------------------------------------------

## Objectives:
By completing this section I aim to:
- Use Bash confidently in daily CLI workflows.
- Understand variables and environment variables.
- Use redirection and pipelines correctly.
- Write small scripts with:
	- conditionals.
	- loops.
	- functions.
- Build scripts that are readable, safe, and reusable.

------------------------------------------------------

## Folder Structure:
This folder contains:
- 'README.md' -> Overview, objectives, and learning plan.
- 'commands.md' -> Bash commands and scripting used in practise.
- 'tests.md' -> Self-tests and scenario questions to verify understanding.

--------------------------------------------------------------------------

## Section Completion Goal:
After completing this section, I should be able to:
- Create and run Bash scripts correctly.
- Handle script inputs safely (arguments, errors, usage output).
- Generate useful outputs (reports, logs, structured text).
- Automate repetitive administrative tasks.
- Read and debug simple scripts written by others.
